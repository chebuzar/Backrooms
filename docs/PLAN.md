## Основа (вибір технологій)

| Що | Вибір | Чому |
|---|---|---|
| Цільові пристрої | iPad/iPhone з **iPadOS/iOS 27+** (Safari), ПК: Chrome, Safari, Firefox | На iPadOS 27 WebGPU гарантовано є — графіка проєктується передусім під WebGPU. |
| 3D-рушій | **Three.js r187, `WebGPURenderer`** (сам перемикається на WebGL 2, якщо WebGPU немає) | WebGPU є в Safari з iOS/iPadOS 26 і в усіх великих браузерах; з r182 це рекомендований рендерер Three.js. Найбільша екосистема й приклади. Babylon.js теж добрий, але бібліотек і прикладів під three.js у рази більше. |
| Шейдери й ефекти | **TSL** (Three Shading Language) + `RenderPipeline` | Один код шейдера працює і на WebGPU, і на WebGL 2. Готові вузли: GTAO/SSAO, Bloom, TRAA, SMAA, плівкові ефекти. |
| Мова | **TypeScript** (строгий режим) | Помилки ловляться до запуску; великий проєкт не розвалюється. |
| Збірка | **Vite** | Швидка збірка, розбиття на частини, які вантажаться за потреби. |
| Фізика й колізії | **Rapier** (`@dimforge/rapier3d-compat`) | Контролер персонажа (сходи, схили, без провалювань), двері, предмети, промені зору. WASM, працює в Safari. |
| Навігація монстрів | **recast-navigation-js** (navmesh + crowd) | Монстри ходять рівнем розумно, обходять перешкоди, не проходять крізь стіни. |
| ШІ монстрів | Власна система (відчуття → пам'ять → стани/поведінка) на TypeScript | Кожен монстр — свої правила; Yuka як довідка (застаріла, без типів). |
| Звук | **WebAudio**: HRTF-просторовий звук, реверберація кімнат, оклюзія крізь стіни | Без важких бібліотек; працює в Safari після першого дотику. |
| Ассети | Blender (headless) → GLB, текстури **KTX2**, геометрія **Meshopt** | Мало пам'яті на iPhone, швидке завантаження. |
| Джерела ассетів | Poly Haven, ambientCG (CC0, без ключа), Sketchfab/Freesound/Meshy (ключі в середовищі) | Лише ліцензії з правом використання; кожен ассет — у `CREDITS.md`. |
| Онлайн | PeerJS (як вимагав власник раніше), окремим етапом | — |

## Потрібна допомога Назара
- 🔑 **Ключі API не приймаються сервісами** (Context7, Meshy, Sketchfab, Freesound): усі збережені значення сервіси відхиляють. Перевірити й вставити заново в налаштуваннях середовища `backrooms` → Network secrets (лише сам ключ, без `Bearer`/`Token`). Без Meshy і Sketchfab моделі монстрів робимо самі (Blender + відкриті CC0-бібліотеки) — це повільніше.
- Злиття гілки в `main`, коли нова гра дійде до готовності (до того сайт показує стару версію).
