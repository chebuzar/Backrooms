## Знайдено й виправлено під час перевірки
- Обстановка рівнів 1–2 не з'являлася (кути речей «у стіні», ряди за межами рівня, у темряві) — виправлено.
- Розмітка паркувальних місць світилася в темряві — тепер освітленість по вершинах.
- Чорне на рівнях 1–2 ставало бірюзовим/синім (тонування в лінійному просторі) — чисті чорні більше не тонуються.
- Петля нервів: серцебиття саме підвищувало небезпеку — тепер воно лише звук.
- Руки галюцинації й тіл стирчали в боки — опущено.
- Прохідний тест не знав про завдання рівнів — тепер виконує їх пішки.

## Чесно: що не перевірено
- **Chromium з WebGPU у цьому контейнері** втрачає відеопристрій навіть на порожній сторінці (оновлений програмний драйвер контейнера; так само й на старій версії з `main`). У GitHub Actions той самий тест проходить. На справжньому Chrome з відеокартою проблеми не очікується, але подивитися варто.
- **Справжній iPad/iPhone/Mac** не перевірено — FPS на пристрої треба подивитися власнику.
- Firefox у цьому проході не запускався.
- Голос гучномовця й плівок — синтезоване «бурмотіння» + субтитри (живого голосу немає).
- Моделі монстрів не переробляли (вони вже радянські: гума Л-1, протигаз ГП-5).
