## Оптимізація для iPad / Mac
- Пресет за пристроєм: Mac — «Ультра», iPad — «Высокое», iPhone — «Среднее». У режимі «Авто» при стабільних < 40 FPS гра сама переходить на пресет нижче; роздільність знижується лише в «Низкой» (правило власника).
- Дальність малювання 70 м (далі все одно повністю ховає туман). Карти світла стиснені (рівень 0: 33 → 22 МБ).

## Чесно: що не перевірено або не зроблено
- **Справжній iPad/Mac не перевірено** — у контейнері лише програмна відеокарта; FPS на пристрої треба подивитися власнику.
- Firefox у цьому проході не перевірявся.
- Не зроблено: гра вдвох (етап 8), особливі кімнати (етап 6), ховання (лише присід, що робить кроки тихими).
- Рівні 1–2 темні (за задумом — ліхтарик); світло запечене у 512² (рівень 0 — 1024²).
