# «Закулисье» — художній стиль, планка якості, бюджет швидкодії

> Оновлено 21.11.2026 за рішенням власника: гра оригінальна (не D9, не Escape the Backrooms, не VHS), **повністю радянська**, психологічний хорор 18+.

## 1. Стиль одним абзацом
**«Радянська плівка» очима людини.** Чистий, чіткий, реалістичний кадр — без рамки, вигину кінескопа, чорних кутів, постійної віньєтки й телевізійного «снігу». Характер дають кольори старої радянської кольорової плівки (ОРВО/«Свема»): трохи вицвілі, теплі світла, зеленкувато-оливкові тіні, стримана насиченість, м'яке червонувате сяйво довкола ламп, дуже дрібне зерно лише в напівтонах. Кожен рівень має свою палітру. Екран темніє й «пливе» **тільки від страху**. Рамка REC з'являється лише тоді, коли гравець сам піднімає відеокамеру «Электроника» (V) — і крізь неї видно те, чого не видно оком.

## 2. Світ — СРСР 1970–80-х, що став неправильним
Знайоме радянське, яке повторюється без кінця й ламається в дрібницях: НДІ, база, гуртожиток, комуналка, хрущовка, парковка з «Жигулями». Американських жовтих кімнат, килимів і «армстронгів» у грі немає.

## 3. Освітлення
- **Запечене глобальне освітлення** (Blender Cycles) — основа: м'які тіні в кутах, відбите світло.
- **Живі шари:** мерехтіння й згасання ламп (впливає й на запечене світло локально), ліхтарик (одна тінь), аварійні лампи, світло Шва.
- **Повітря:** легкий серпанок з глибиною в кольорі палітри рівня.
- **Реакція світу на небезпеку:** лампи гаснуть рядами, мерехтять у ритмі кроків монстра; **гул зникає** — тиша як загроза.

## 4. Постобробка («радянська плівка», `src/render/post.ts`)
- Тональна корекція **ACES** (правило власника: AgX або ACES), потім плівкова крива: трохи підняті чорні, м'яке плече світел.
- **Плівковий грейдинг на рівень** (`FILM` у `post.ts`): тінь / середина / світло — свої відтінки, насиченість, «вицвітання». Рівень задає палітру при завантаженні.
- Halation: ледь червонувате сяйво довкола найяскравіших ламп (через bloom).
- Зерно — дрібне, лише в напівтонах (не в тінях, не «сніг»). AO (GTAO), Bloom, TRAA.
- **Тільки від страху:** затемнення країв, легка аберація, «пливе» картинка, приглушення кольору.
- **Режим камери (V):** видошукач «Электроника» — REC, лічильник, заряд, перехрестя; ледь холодніший кадр; камера показує приховане.
- **Без:** вигину, чорних кутів, постійної віньєтки, VHS-смуг, пікселізації, «снігу».

## 5. Матеріали й деталі
- Лише справжні PBR-текстури (колір, нормалі, шорсткість, AO) з CC0 (ambientCG, Poly Haven, ShareTextures) — «перефарбовані» під радянські кольори. **Жодних текстур поверхонь, намальованих кодом.**
- Правильний масштаб: шпалери — рулон ~0.53 м, плита «Акмигран» 0.6×0.6 м, паркетна планка ~7×35 см.
- Варіативність: змішування текстур за масками (волога, кіптява, затерте), декалі, модульні деталі. **Двох однакових стін поруч не буває.**

## 6. Референси (словами)
- **Радянські НДІ, інститути, бази 1970–80-х, Прип'ять:** олійна фарба до 1.5 м, побілка, лінолеум, «Акмигран», таблички, дермантинові двері.
- **Сталкер (Тарковський):** вицвілі кольори, вода, повільність, тиша.
- **P.T.:** дрібна зміна знайомого = великий страх.
- **Amnesia / SOMA:** напруга без скримерів, документи як голос світу.

## 7. «Планка якості» — що для нас означає «як від студії»
Кожен кадр має проходити цей список (перевіряю скріншотами Chromium WebGPU/WebGL + WebKit + iPad/iPhone):
1. Немає видимих швів, мерехтіння поверхонь, «дір» у геометрії, чорних смуг і кілець; кадр чистий, без рамки.
2. Матеріали читаються зблизька (лінолеум, шпалери, побілка, ДСП).
3. Будь-який кадр, зроблений навмання, цікавий і впізнавано радянський.
4. Світло правдоподібне: звідки воно, видно; тіні м'які; кольори «плівкові», не «пластикові».
5. Текст і інтерфейс — охайні, читаються на iPhone, стиль радянської документації; на екрані без потреби нічого немає.
6. Звук ніколи не мовчить повністю — крім тиші як події.
7. 60 кадрів на сучасному iPad/MacBook (див. бюджет), без ривків при завантаженні.

| Draw calls у кадрі | ≤ 250 | ≤ 150 |
| Трикутників у кадрі | ≤ 1.5 млн | ≤ 600 тис. |
| Пам'ять текстур (GPU) | ≤ 500 МБ | ≤ 300 МБ |
| Пам'ять JS | ≤ 250 МБ | ≤ 200 МБ |
| Розмір першого завантаження (меню + рівень 0) | ≤ 35 МБ | те саме |
| Кожен наступний рівень | ≤ 40 МБ, вантажиться в фоні | те саме |
| Час до гри (50 Мбіт/с) | ≤ 10 с | ≤ 15 с |
| Тіні в реальному часі | 1 (ліхтарик) + 1 (сюжетна лампа) | 1 |
