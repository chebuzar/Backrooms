# Технічний борг — що переробити на найкраще

Сюди Claude записує все застаріле або зроблене не найкраще (правило `CLAUDE.md` → 2.2).
Переробляти по черзі, починаючи з 🔴. Кожне виправлення — окремий коміт після зеленого `npm run check`,
потім перенести рядок у «Зроблено».

Важливість: 🔴 висока (заважає якості, швидкодії чи Safari) · 🟡 середня · 🟢 низька.

**Перший прохід — 22.11.2026:** `npm outdated`, `npm audit`, огляд коду й конфігів (Three.js r187, Vite 8, ESLint, CI),
плюс лінтер із типами, який тепер сам ловить застарілі (`@deprecated`) API. Результат огляду коду: у `src/` **немає жодного
застарілого API** (перевірено правилом `no-deprecated` на всіх `.ts`), рендер уже на `RenderPipeline` + TSL, звук — на
сучасному `AudioParam` API.
